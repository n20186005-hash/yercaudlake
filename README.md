# ஏற்காடு ஏரி மற்றும் படகு இல்லம் — தமிழ் பயண வழிகாட்டி

சேலம் மாவட்டம், தமிழ்நாட்டில் உள்ள ஏற்காடு ஏரி / பெரிய ஏரி / எமரால்ட் ஏரி மற்றும் படகு இல்லத்திற்கான சுயாதீன, இலாப நோக்கமற்ற தகவல் தளம்.

## தொழில்நுட்பம்
- Astro 7.2.4
- Tailwind CSS 4.3.3
- TypeScript 6.0.3
- @astrojs/check 0.9.10
- @astrojs/sitemap 3.7.3
- pnpm 11.23.0
- Node.js 24.19.0
- Cloudflare Workers Static Assets
- தரவுத்தளம், உள்நுழைவு, CMS இல்லை

`package.json` மற்றும் `pnpm-lock.yaml` ஒரே உண்மையான resolver graph-இல் இருந்து ஒத்திசைக்கப்பட்ட exact-version தொகுப்பை பயன்படுத்துகின்றன. புதிய patch பதிப்பை lockfile-ஐ உண்மையாக மறுபரிசீலனை செய்யாமல் கைமுறையாக எழுதவில்லை.

## டொமைன்
உற்பத்தி டொமைன் `SITE_URL` சூழல் மாறி வழியாக `astro.config.ts`-இன் `site` மதிப்புக்கு ஒரே இடத்தில் செல்கிறது. மதிப்பு இல்லாவிட்டாலும் build வடிவமைப்பின் அடிப்படையில் இயங்கும்; absolute canonical/OG URL மற்றும் sitemap அப்போது உருவாக்கப்படாது. உண்மையான டொமைன் அமைக்கப்பட்டால் மட்டுமே `@astrojs/sitemap` செயல்படும்.

## இயக்கம்
```bash
corepack enable
CI=1 corepack pnpm install --frozen-lockfile
pnpm check
pnpm build
```

Cloudflare வெளியீடு:
```bash
pnpm deploy
```

## தனியுரிமை
GA4 அளவீட்டு அடையாளம் `G-HXM22WWPKP`. பகுப்பாய்வு தேர்வு `/cookies/` பக்கத்தில் அனுமதிக்கப்பட்ட பிறகே Google Analytics script ஏற்றப்படும். தனியுரிமைக் கொள்கை, சேவை விதிமுறைகள் மற்றும் குக்கீ அமைப்புகள் தனித்தனி இரண்டாம் நிலைப் பக்கங்கள்.

## புகைப்படங்கள்
உறுதி செய்யப்பட்ட ஏற்காடு உண்மை புகைப்பட மூலங்கள் மற்றும் உரிமங்கள் `PHOTO-SOURCES.md`-இல் உள்ளன. இந்த sandbox வெளிப்புற binary கோப்புகளை பதிவிறக்கத் தடுப்பதால் உண்மை JPG binary-கள் இந்த நிலைத் தொகுப்பில் இல்லை; தவறான இடப் படங்களால் அவற்றை மாற்றவில்லை.
